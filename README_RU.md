# Редизайн меню по Visuals.png — версия 5

Это обновление исходников существующего проекта, а не отдельный проект и не собранный Windows-бинарник.

## Установка

1. Сделайте резервную копию проекта и текущего файла конфигурации.
2. Откройте папку `Smite_Internal222` из этого архива.
3. Скопируйте её содержимое в корень вашего проекта — туда, где уже находятся `ui`, `core` и `features`. Разрешите замену пяти файлов, перечисленных ниже. Не создавайте лишнюю вложенную папку `Smite_Internal222`.
4. Пересоберите проект в своей текущей конфигурации Visual Studio. Файлы решения и проекта менять не требуется.
5. Откройте меню. При необходимости используйте Ctrl+0 для масштаба 100% и подгонки окна.

## Изменённые файлы

- `ui/menu.cpp` — общая компоновка всех шести разделов, широкая навигация с подписями, заголовки, вкладки с подчёркиванием, сетки карточек и закреплённая нижняя панель.
- `ui/theme.cpp` — общие визуальные компоненты, палитра, шрифты, компактные переключатели, кнопки и рамки.
- `ui/theme.h` — размеры, значения новой темы по умолчанию и шрифт заголовков карточек.
- `core/performance.h` — только оформление панели настроек диагностики; измерения не изменены.
- `features/config.cpp` — только два изменения версии оформления: 4 → 5 при сохранении и загрузке.

## Что важно

- Новая тема — непрозрачный тёмный фон, светло-голубой акцент, умеренное скругление, как в присланном макете.
- Конфигурация старой версии получает новую палитру вместо старого оформления. Существующие функциональные настройки не сбрасываются. Для сохранения новой версии профиля используйте Save changes.
- Дополнительные настройки целей, дальность лагерей, настройки вардов, Corner Length и Visible Check доступны в Visuals → Details. Цвета доступны в Colors.
- Сброс конкретного раздела перенесён на значок круговой стрелки в верхней полосе. Подтверждение сброса сохранено.
- Минус и крестик скрывают меню, а не закрывают приложение. Прежние горячие клавиши открытия сохранены.
- Превью справа — статическая иллюстрация расположения элементов, без данных игры. Она не является точной симуляцией текущих функциональных переключателей.
- На скриншотах использованы демонстрационные состояния переключателей; ваши сохранённые значения могут отличаться.
- Встроенные панели модулей используют общую тему. Исходники этих модулей, SDK, hooks и графические backend-файлы не изменены.

## Проверка и ограничения

- Изменённые `menu.cpp`, `theme.cpp`, `theme.h` и `performance.h` скомпилированы на автономном Linux-стенде с версией Dear ImGui из исходного архива и заглушками платформенных/игровых вызовов.
- Проверены общая вёрстка шести разделов, переключение представлений стендом, узкое окно 900×700 и масштаб 150%. Внешние панели модулей на стенде заменены заглушками: их содержимое требует проверки в исходном проекте.
- Сравнение исходников подтвердило сохранение набора привязок к `cfg` и отсутствие изменений блока вызовов runtime-сервисов в `Menu::Draw`.
- Полная сборка MSVC, Windows-линковка, DirectX 11/12 и работа меню в исходном окружении здесь НЕ проверялись. `features/config.cpp` проверен сравнением двух изменённых строк, а не полной сборкой проекта.

Папка `preview` содержит изображения автономной отрисовки, не скриншоты работающего исходного проекта. `menu_redesign.patch` — текстовый diff для проверки изменений. Для отката верните пять исходных файлов и резервную копию конфигурации.
